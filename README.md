# RTOS Projects

A collection of small projects and experiments for learning real-time
operating systems and embedded software.

I’m starting with Zephyr RTOS on Linux using its `native_sim` target, so I
can write and run RTOS applications without a physical development board.

## Learning goals

- Practice RTOS concepts such as threads, scheduling, queues, and synchronization.
- Build and run small C applications with Zephyr.
- Become familiar with the RTOS development workflow before trying a physical board.

## About the simulator

`native_sim` builds a Zephyr application as a Linux executable. It is useful
for learning and testing application code, but it does not emulate a specific
microcontroller or board.
